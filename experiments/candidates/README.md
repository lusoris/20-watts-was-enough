# Candidate experiment contracts

| ID | Contract | Question |
| --- | --- | --- |
| 001 | [Adaptive logical topology](001-adaptive-topology.md) | Does changing the graph itself beat routing over fixed topology after migration, reserve, and recovery costs? |
| 002 | [Multiscale context broadcast](002-multiscale-context-broadcast.md) | Does a rate-limited broadcast with receiver-specific temporal decoding beat ordinary gates, global tokens, and supervisory control? |
| 003 | [Recovery dynamics as fragility sensing](003-recovery-dynamics-fragility.md) | Do bounded probes reveal hidden loss of restoring margin earlier than SLOs, change detection, and standard system identification? |

These are pre-implementation contracts, not evidence that a candidate works.
Passing a simulator stage permits a higher-fidelity test; it does not promote a
principle by itself.
