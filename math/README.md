# Mathematical notes

Mathematics here supports the concept; it does not conceal assumptions behind
notation.

- [`notation.md`](notation.md) defines shared symbols, units, and boundaries.
- [`efficiency-model.md`](efficiency-model.md) derives the first testable cost
  model and explains why the inherited brain/GPU ratio is invalid.
- [`memory-lifecycle.md`](memory-lifecycle.md) defines a constrained replay,
  consolidation, and forgetting controller.

Rules:

1. Define every symbol before use.
2. Keep energy (joules), power (watts), operations, bytes, time, and task quality
   dimensionally distinct.
3. State whether a value is measured, cited, estimated, or hypothesized.
4. Never compare efficiencies unless task, quality, boundary, precision, and
   time basis match.
